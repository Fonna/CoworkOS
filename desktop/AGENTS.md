# Electron 宿主

桌面拥有窗口、可信 IPC、加密配置、数据目录与本地后端。业务服务和共用 UI 分别在 `src/` 与 `web/`，不要在桌面复制一套。

- 原生能力只接受可信主窗口的主 frame；产出物预览窗口不暴露 preload/Node。新增 IPC 必须做发送方与参数验证。
- 后端启动使用就绪通知、随机端口与会话 token，不依赖固定端口或延时猜测。
- 密钥只由宿主读取/保存，不进入 renderer 状态和安装包。
- 退出先等待文档与草稿保存，再关闭后端、Run 进程组和 MCP；保存失败要保留可恢复状态。
- 用户数据与安装资源分开，升级不覆盖用户配置。开发与已安装应用路径都要验证。

运行 `test/desktop-*.test.js` 对应回归；窗口、退出和打包变更还需 [Mac 发布](../docs/mac-release.md) 的原生 smoke。记录锁屏、权限、平台跳过，不能等同通过。
