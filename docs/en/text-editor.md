# Text editor reference

English | [中文](../text-editor.md)

## Open and edit

Create a document in Applications → Text editor, or open a `.txt`, `.md` or `.markdown` file. Markdown is edited as source text.

To ask CoworkOS for changes, save, select the target passage, return to the conversation and send a request. For example:

```text
Rewrite the selected passage as a project progress update. Preserve every number, date and proper noun, remove repetition, and change only the selection.
```

Without a selection, name the heading, paragraph or range to change in your request.

## Save and download

Edits save automatically. Click Save or press ⌘/Ctrl+S to save immediately. Check the status bar for the result. If saving fails, preserve your draft before resolving the error.

Both automatic and manual saving write back to original files opened in the desktop App. When a browser cannot obtain a native file path, it uses a managed copy. The download button saves a separate TXT or Markdown file.

## Conflicts and recovery

Use change comparison to inspect differences, History to review edits by you and CoworkOS, and Undo to reverse the previous change.

A version conflict preserves your draft and pauses automatic saving. Copy your draft before loading the latest version and merging, or merge in the editor and select Save merged content. Loading the latest version discards the current draft.
