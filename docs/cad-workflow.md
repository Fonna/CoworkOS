# CAD 工作台（兼容）

中文 | [English](en/cad-workflow.md)

此工作台保留已有 CAD 文档的编辑能力。新的三维建模任务使用[CAD Harness](external-applications.md#cad-harness)；已有 CadQuery 工程的精确计算仍需[CAD 组件](optional-components.md)就绪。

## 打开已有设计

从原会话或应用面板的文件列表打开已有 CAD 文档。工作台保留 CAD JSON 工程、已导入的 Python 和 JSCAD 设计；Python 使用 CadQuery，JavaScript/JSCAD 使用 JSCAD。

需要 CoworkOS 修改已有设计时，先在对话中加载该文档，再说明尺寸、单位和约束。

## 调整与检查

点击“代码”编辑建模源码，再点击“更新模型”查看计算结果。模型声明了可调参数时，可在“属性”中修改。选中零件后可查看其属性，在“部件”中查找或切换显示。

通过观察方向、适应视图、透明/线框、剖切和爆炸图检查模型。“检查”集中显示模型检查结果、计算失败原因和日志；显示调整不修改设计源码。存在运动轨道的工程可以播放运动，播放结果不代表动力学或碰撞验证。

已有基础形体文档仍可添加方体、圆柱、球体，修改尺寸、位置和旋转，并进行合并或切除。该模式提供 JSON 和 STL 导出，也可以升级为 JSCAD 源码工程。

## 保存与导出

点击“保存”或按 ⌘/Ctrl+S 保存设计；“撤销”撤回上次保存。更新模型用于预览，仍需保存设计。通用文件行为见[文件与应用](task-workspace-layout.md#产出物与草稿)。

在“文件 → 导出”选择交付格式：

| 格式           | 用途与范围                             |
| -------------- | -------------------------------------- |
| 完整工程 JSON  | 保留源码、参数及工程信息，便于继续编辑 |
| Python / JSCAD | 下载当前引擎的建模源码                 |
| STEP           | CadQuery 的精确实体与装配交换格式      |
| STL            | 静态三角网格                           |
| PNG            | 四视图或当前视图                       |

计算失败时先查看原因、修正源码或参数，再重试；复杂模型可以在代码区延长生成时限。组件缺失或被停用时，使用“在设置中安装”检查状态。

外部 build123d 工作流见[CAD Harness](external-applications.md#cad-harness)；引擎、参数协议与开发细节见[CAD 技术参考](cad-integration.md)。
