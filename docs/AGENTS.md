# 文档维护

阅读导航见 [README](README.md)，完整约定见 [文档维护](documentation.md)。

- 每个事实由一个主文档维护；命令、配置、架构、HTTP、持久数据、测试和发布分别归对应指南。
- 使用与接口指南描述现行行为；未交付能力进入路线图并附完成标准。
- 路径/命令变化同步代码地图和用户入口；示例对照 package/scripts/CLI help。
- 不提交真实密钥、私有服务、个人配置、用户任务或操作流水。配置使用占位符，数据路径采用通用示例。
- 源码使用相对 Markdown 链接。迁移或删除文档时更新所有消费者，运行 [链接检查](testing-local-run.md)。
- 核心用户/开发入口提供双语：根文档使用 `.en.md`，英文指南放 `en/`。同一变更同步命令、字段、能力和限制；未翻译的专项接口注明语言。
