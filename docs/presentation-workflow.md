# PPT 编辑参考

中文 | [English](en/presentation-workflow.md)

## 生成与修改

从材料生成独立 PPTX 时，提供资料文件、听众、时长和交付路径。PPT 编辑器的导入、编辑与导出能力见[应用功能](applications.md)。

修改已有文稿时，在“应用 → PPT”中打开文件，返回对话并写明页码和需要保留的内容。例如：

```text
把第 3 页拆成两页：第一页保留方法和原图，第二页放实验结果。保留现有主题、图注与数据，不改其他页面。
```

正在编辑文字时，先结束当前输入，再让 CoworkOS 修改。可在编辑器中检查和调整结果。

## 保存与导出

人工修改会保留为恢复草稿。关联本地文件时，点击“保存”或按 ⌘/Ctrl+S 才写回原文件；切换、导出和关闭文稿只保留草稿。

在导出面板选择 PPTX。保留一份 JSON/PPTIST 源文件，方便继续编辑；PPTX 转换可能改变复杂布局、动画或字体。

交付前逐页检查数字、来源、文字重叠、图表标签和图片裁切。独立 PPTX 的生成命令、渲染依赖和检查参数见[演示文稿工具参考](presentation-reference.md)。

## 视觉连接

自动看图检查需要支持图像输入的模型。日常聊天使用纯文本模型时，可在“模型连接”中保存一组视觉配置，勾选“用此连接分析图片，供纯文本模型使用”。设置方法见[模型配置](configuration.md)。
