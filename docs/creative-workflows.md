# 网页制作参考

中文 | [English](en/creative-workflows.md)

## 已有项目

把项目目录设为工作目录，说明要修改的页面、主要操作和需要保留的设计。CoworkOS 会沿用项目的框架、依赖与运行命令。例如：

```text
读取当前项目，在活动列表页增加日期筛选。沿用现有组件和配色，筛选后同步更新列表与计数，保留其他筛选条件。完成后运行项目已有检查，并给出本地预览方式。
```

## 独立网页

提供内容、数据和素材，写明入口文件与交付目录。离线使用时，要求包含脚本、字体、图片及其许可，不引用外部 CDN。

检查独立网页时可使用本地 HTTP 服务。机器已有 Python 3 时，在项目目录运行：

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory event-site
```

在浏览器打开 `http://127.0.0.1:8000/`；结束预览后在终端按 Ctrl+C。把 `event-site` 替换为实际目录。

## 交互与动画

原型需要说明主要操作、示例数据或实际接口，以及刷新后是否保留输入。要求筛选、表单和按钮产生真实反馈，并检查键盘操作与窄屏布局。

浏览器动画需说明时长、画幅和关键动作。MP4 等视频交付需要实际捕获、编码和播放检查；尚未编码的产物仍是网页动画。

需要上线时，给出已配置的目标平台并明确部署要求；本地预览地址只能在当前机器使用。
