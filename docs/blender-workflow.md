# Blender 工作台（兼容）

中文 | [English](en/blender-workflow.md)

此工作台保留已有 Blender 文档的编辑能力。新的三维任务使用[Blender Harness](external-applications.md#blender-harness)；已有工程的建模执行、原生导入和渲染仍需[Blender 组件](optional-components.md)就绪。

Windows 可配置[本机 WSL2 Blender 执行器](windows-blender.md)，用于此内置工作台；无需切换至 Mac。

## 打开已有工程

从原会话或应用面板的文件列表打开已有 Blender 文档。在已有工作台中，“文件 → 导入 .blend 工程”可载入原生文件；文件须非空且不超过 64 MiB，导入前先在 Blender 中打包贴图并本地化链接库。

需要 CoworkOS 继续修改时，在对话中加载工程，再说明场景、尺寸、材质和交付格式。

## 编辑场景

在视图或对象列表中选择对象，可以修改名称、位置、旋转和缩放。支持的对象还可调整颜色、金属度与粗糙度；点击“保存”后更新场景。位置使用 Blender 场景单位，旋转使用度。

点击“代码”可编辑 Python/bpy 源码与 JSON 参数。“保存”保留源码草稿；“运行并保存场景”才执行代码。运行前可选择时限；“运行前清空场景”仅在明确需要重建时启用。

“查看渲染图”切换到渲染结果，适应按钮显示完整场景。“修改对比”查看版本差异，“撤销”恢复上次修改。当前属性面板提供对象级和基础材质编辑，复杂拓扑、节点、骨骼等可通过 bpy 或外部 Blender 处理。

## 保存与导出

点击“保存”或按 ⌘/Ctrl+S 保存。保存成功后再检查预览；预览加载失败时，可使用“重试预览”。

“文件”菜单提供：

| 格式   | 内容                                                                |
| ------ | ------------------------------------------------------------------- |
| .blend | 原生工程，适合备份与继续编辑                                        |
| GLB    | 用于预览、引擎或其他工具的派生模型，与完整 Blender 场景存在格式差异 |
| PNG    | 场景渲染图                                                          |
| Python | 建模源码草稿                                                        |

除 Python 外，导出需要先成功生成场景。需要可移植备份时，下载 `.blend`；仅复制工作台的工程清单不能保留完整场景。

遇到冲突或保存结果待确认时，先按界面提示重试或备份草稿；“重新载入”会放弃当前修改。原文件与管理副本的行为见[文件与应用](task-workspace-layout.md#产出物与草稿)，执行限制与开发细节见[Blender 技术参考](blender-integration.md)。
