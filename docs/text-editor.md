# 文本编辑参考

中文 | [English](en/text-editor.md)

## 打开与修改

在“应用 → 文本编辑器”中新建文档，或打开 `.txt`、`.md`、`.markdown` 文件。Markdown 以源码方式编辑。

需要 CoworkOS 修改时，先保存，选中目标段落，再从工作区更多菜单选择“在对话中使用”并发送要求。例如：

```text
将选中段落改写为项目进展说明，保留所有数字、日期和专有名词，删去重复表达。只修改选中部分。
```

没有选区时，在请求中写明文档中的标题、段落或修改范围。

## 保存与下载

编辑会自动保存，也可点击“保存”或按 ⌘/Ctrl+S。以状态栏中的保存结果为准；保存失败时，先保留当前草稿再处理错误。

桌面端打开原文件后，自动保存与手动保存都会写回原文件。浏览器无法取得本机路径时，使用管理副本；下载按钮可另存 TXT 或 Markdown 文件。

## 冲突与恢复

“修改对比”查看版本差异，“历史”查看人工和 CoworkOS 的修改记录，“撤销”撤回上一次修改。

发生版本冲突后，草稿保留，自动保存暂停。先“复制我的草稿”，再载入最新版本并合并；也可在编辑区完成合并后点击“保存合并后的内容”。“载入最新版本”会放弃当前草稿。
