# CoworkOS 0.1.0

The first npm release provides the CoworkOS CLI and an explicit installer for the independent Mac App.

```sh
npm install -g coworkos-app@0.1.0
coworkos desktop install
```

Alternatively, install the App with `npx coworkos-app@0.1.0 desktop install`. Node.js 22.19.0 or newer is required for these commands. The App installs in `~/Applications` and runs without Node.js. Existing Apps are protected from replacement; update an installed App in Settings. npm manages CLI updates with `npm install -g coworkos-app@latest`.

## Changes

- Publish the `coworkos-app` npm package with locked production dependencies, upstream licenses and official npm download URLs. Desktop downloads occur only after an explicit command.
- Verify the Mac download size and SHA-256, App identity, version, architecture and strict signature before installation. Use a read-only image and an atomic install without administrator access.
- Add Markdown preview with sanitized rendering, math support and third-party notices.
- Keep the document editor visible when switching between split and full-width views in Electron by placing responsive size containment on its host.
- Preserve long-task cancellation checkpoints, release completed polling listeners and retain the original metadata of previously published scientific tool catalogs.

## Validation

The full local verification run built the application and passed lint, types, formatting, documentation links, source hygiene and release-runner checks. Its Node suite recorded 3,026 passes, 28 failures and 58 skips. After correcting the reported product and test-fixture issues, a combined rerun of every failed file plus installer/update coverage recorded 200 passes, 5 skips and no failures; the entire Node suite was not repeated after these corrections. The affected browser editor suite passed all 7 cases.

The final DMG passed hdiutil verification and strict codesign checks. A fresh temporary installation through the actual installer passed App verification, installation, backend/UI startup and normal exit. Package review confirmed that private configuration, user work and documentation build dependencies were excluded, and that bundled third-party license/source materials were present. These results are local release-Mac evidence; independent acceptance limits are listed below.

## Support and limitations

The desktop App supports Apple Silicon on macOS 14 or newer. This initial distribution uses ad-hoc signing and has no Developer ID signature or Apple notarization. If macOS blocks the first launch, use the normal approval flow in System Settings → Privacy & Security. Do not disable system protection.

This version starts a separate CoworkOS update feed at version 0.1.0. Legacy Atria releases and their update feed remain separate; the first transition from Atria requires manual installation of CoworkOS. Configuration and work remain in the existing data locations. Back up important data before upgrading.

Known desktop issue: reopening an existing PPT after restarting the App can show a blank editor even after the presentation has loaded. PPT editing and saving have not completed native acceptance. The complete packaged desktop smoke suite remains incomplete; several startup/navigation assertions are outdated.

Validation on the release Mac does not certify installation on another clean machine, actual model providers, real microphone or accessibility permissions, Gatekeeper acceptance of a quarantined download, Linux installation, Intel Macs or Windows. CAD and Blender component delivery has its own acceptance scope. Third-party software retains its own licenses; see THIRD_PARTY_NOTICES.md and the license/source materials in the distributed artifacts.
