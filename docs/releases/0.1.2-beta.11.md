# Atria 0.1.2-beta.11

本版通过 [PR #82](https://github.com/ignorejjj/Atria-Cowork/pull/82) 将默认 Mac 安装包改为小包：PPT 编辑器随包提供，CadQuery/Python 与 Blender 在首次启动后自动下载并安装。组件来自独立的[公开组件 Release](https://github.com/ignorejjj/Atria-Components/releases/tag/components-v1)，无需 GitHub 账号、token 或邀请码。

## 下载与安装

- Mac：`Atria-0.1.2-beta.11-mac-arm64.dmg`，支持 macOS 14+、Apple Silicon。CAD 与 Blender 首次安装需要网络，普通会话可在组件准备期间使用。
- CLI：`atria-cowork-cli-0.1.2-beta.11.tgz`，要求 Node >=22.19.0 和 npm；安装需要网络及安装脚本，尚未发布到 npm registry。
- 同时下载并核对对应的 `.sha256`、发行清单和 Mac 签名报告。最终大小、来源提交和校验值以本版附件为准。主仓库保持私有时，下载本版 DMG 与 CLI 仍需仓库访问权限；公开组件下载独立于该权限。

{{MAC_SIGNING_NOTICE}}

本版 Mac 测试包采用 ad-hoc 签名，尚未公证，通过校验后的 DMG 手动安装或替换。首次打开被系统拦截时，在“系统设置 → 隐私与安全性 → 仍要打开”中确认。升级前退出任务并备份用户数据及外部项目。详见[安装指南](../getting-started.md)。

## 组件安装变化

- 启动后自动准备缺失的 CAD 与 Blender，界面显示下载与安装进度，支持取消和失败后重试。
- 已安装且兼容的组件可在主程序升级后复用；组件禁用和主动取消状态会保留。
- PPT 编辑器内置于小包，安装后即可使用。组件来源、校验、存储位置与恢复说明见[可选组件](../optional-components.md)。
- 运行时附件与对应源码、许可材料发布在公开组件仓库；App 仅自动下载运行时。自有代码采用 MIT，第三方组件遵循各自许可，见[第三方声明](../../THIRD_PARTY_NOTICES.md)。

## 验证与限制

本版最终 DMG、CLI 的构建、安装和自动化验收结果将单独附在 Release 验收记录中。此前功能实现的验证记录不能替代本版最终产物验收；未执行或跳过的检查不计为通过。

- 另一台无开发环境 Mac 的首次安装和升级、真实模型任务仍待独立验收。
- Developer ID 签名、公证及 Gatekeeper 下载隔离属性验收尚未完成；本版不提供签名 ZIP 自动更新。
- 本轮发行支持范围为 Apple Silicon Mac；Intel Mac、Windows 与 Linux 安装未验证。

## English release summary

This beta ships a smaller Mac DMG. PPTist remains bundled; missing CadQuery/Python and Blender components install automatically from the [public component release](https://github.com/ignorejjj/Atria-Components/releases/tag/components-v1), without a GitHub account, token or invitation code. Installation shows progress, supports cancellation and retry, and reuses compatible components across app upgrades. Ordinary conversations remain available while components are being prepared.

The Mac package targets Apple Silicon on macOS 14+, uses ad-hoc signing and is not notarized. Install or replace it manually using the verified DMG. The CLI requires Node >=22.19.0, npm, network access and installation scripts; it is not published to the npm registry. Downloads from the private application repository still require repository access.

Final package validation is recorded separately in the Release acceptance addendum. Previous implementation checks do not certify these final artifacts. Installation and upgrade on a separate clean Mac, real-model tasks, Developer ID signing, notarization and other-platform installation remain unverified. Back up user data and external projects before upgrading.
