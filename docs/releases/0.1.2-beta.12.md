# Atria 0.1.2-beta.12

本版把安装版主程序更新接到独立的公开分发仓库，开发源码继续保持私有。无需 GitHub 登录、邀请码或下载 token。

## 更新体验

- 设置中只保留一个更新按钮，不再选择预览版或稳定版。发现新版时，侧栏底部显示蓝色圆形下载提醒，点击查看更新。
- 点击“下载更新”后可以继续聊天和编辑；校验完成后点击“重启并安装”。安装前保存文档与草稿，并要求运行中的任务先结束。
- 在用户可写的安装位置中，App 从校验后的 DMG 准备候选，退出后替换并重开，保留旧 App 备份；失败时保留或恢复旧版。安装目录不可写时提示使用系统安装方式。
- 主程序、CLI 从公开静态清单读取维护者指定的当前版本，绑定精确文件名、大小、SHA-256 和固定 Release，不再依赖 GitHub 匿名 Releases API 额度。CLI 显式通道参数仅保留旧发行路径的兼容。
- CAD/Blender 继续从独立公开组件仓库自动准备；内置 PPT 和已经安装的兼容组件保持可用。

## 安装与支持范围

Mac DMG 适用于 macOS 14+、Apple Silicon。此 beta 为 ad-hoc 签名，尚无 Developer ID 签名或 Apple 公证；系统可能要求正常批准打开，不要关闭系统安全保护。首次安装使用 DMG。beta.11 及更早安装包尚未包含这套公开更新逻辑，升级到本版需要先安装本版 DMG，之后使用应用内更新。

CLI 使用对应 `.tgz`，要求 Node >=22.19.0、npm、网络和安装脚本。CLI 尚未发布到 npm registry。下载同时核对 `.sha256`、发行来源清单和 Mac 签名报告。

用户数据仍保留在原有目录；更新程序不删除配置、会话、任务、外部项目或受管组件。升级前备份重要数据。发布者、固定版本与文件校验值以本版附件为准。

## 验证与限制

最终候选的构建、Node 回归、浏览器、原生安装/回滚和真实公开下载结果由 Release 验收附录单独记录。未执行、失败、跳过及历史候选结果不记作本版通过。另一台无开发环境 Mac、真实模型、真实系统授权、Gatekeeper 下载隔离属性和其他平台安装仍需独立验收。

## English

Atria now keeps application development private while distributing installers and a single public update feed through Atria-Releases. No GitHub login, invitation or token is required. The App has one update action and a blue sidebar reminder, without a stable/preview selector. Download while continuing to edit, then choose “Restart and install”. The host saves documents/drafts and checks active tasks before installation.

In a user-writable location, the managed installer verifies the DMG and App identity, version, architecture and strict signature; it replaces the App after exit, retains the previous App and restores it on installation failure. Unwritable locations require system installation without automatic elevation. Public checks use static metadata and exact fixed-release assets rather than the anonymous GitHub Releases API. Existing user data and compatible runtime components retain their paths.

This beta supports Apple Silicon on macOS 14+, with ad-hoc signing and no Apple notarization. Approve launch through the normal macOS flow if required; never disable system security. Versions beta.11 and earlier need a one-time manual upgrade to this DMG before the new in-app update flow becomes available. The CLI requires Node >=22.19.0, npm, network and installation scripts. Final-candidate acceptance is recorded separately; clean-machine installation, real providers, actual system permissions, downloaded-quarantine acceptance and other-platform installation remain independent checks.
