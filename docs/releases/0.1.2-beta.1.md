# Atria 0.1.2-beta.1

此版本为未对外发布的内部候选；后续公开测试候选见 [0.1.2-beta.7](0.1.2-beta.7.md)。

完整 App 验收发现独立项目应用加载到会话时返回 422，此候选未通过发布验收。修复与最终包按新版本记录，不移动此 tag 或覆盖旧候选产物。

此候选提供本地多智能体 CLI 和 Mac 文档工作台。需要自备兼容的模型服务、模型 ID 与 API Key。安装包是否已经开放下载以本版 GitHub Release 的发布状态为准。

## 下载与安装

从本版 Release 的 Assets 下载对应文件及其 .sha256：

| 产物                                      | 要求与用途                                                      |
| ----------------------------------------- | --------------------------------------------------------------- |
| Atria-0.1.2-beta.1-mac-arm64.dmg          | macOS 14+、Apple Silicon；内置 Node 与 CadQuery/Python          |
| atria-cowork-cli-0.1.2-beta.1.tgz         | Node >=22.19.0、npm；macOS / Linux 目标平台，实际验收按下文记录 |
| Atria-0.1.2-beta.1-mac-arm64.signing.json | 实际 ad-hoc 签名、权限、系统要求与公证状态；另附 .sha256        |
| atria-release-0.1.2-beta.1.json           | 来源提交、tag、文件大小与 SHA-256；另附 .json.sha256            |

Mac 在下载目录执行：

```sh
shasum -a 256 -c Atria-0.1.2-beta.1-mac-arm64.dmg.sha256
```

打开 DMG，将 Atria 拖入 Applications。测试版使用 ad-hoc 签名，**未做 Developer ID 签名与 Apple 公证**。首次打开被拦截时，核对来源和校验值后，通过“系统设置 → 隐私与安全性 → 仍要打开”批准此 App。[Apple 说明](https://support.apple.com/zh-cn/102445)。

CLI 在包所在目录安装：

```sh
shasum -a 256 -c atria-cowork-cli-0.1.2-beta.1.tgz.sha256
npm install --global --prefix "$HOME/.local" ./atria-cowork-cli-0.1.2-beta.1.tgz
export PATH="$HOME/.local/bin:$PATH"
atria --version
atria init
atria doctor
atria
```

Linux 用 sha256sum -c 校验。将 PATH 设置加入自己的 shell 配置以便重开终端后使用。尚未发布到 npm registry。完整配置、权限与恢复步骤见 [安装指南](../getting-started.md)。

## 本版改进

- 补齐 Mac 原生中文语音输入、麦克风与语音识别权限声明，以及停止、取消和超时清理。
- 修复多会话并发发送和新草稿归属，避免后台请求影响另一个会话的输入和发送状态。
- 加强 Main Inbox 的持久投递、进程重启恢复和 Watch 唤醒，修复故障重试与会话边界。
- 补齐应用写入和重命名的崩溃恢复，保护工作区和符号链接边界。
- 修复 PPT 表格内容过滤、内联格式及即时保存导出，改进项目草稿、工作台导航和界面层级。
- CLI 在启动服务前检查命令参数，提供安装包入口和完整发行来源清单。
- 采用单一长期 main 与临时 PR 分支，发行版本由不可移动的 tag 和 Release 保存。

## 验收范围与已知限制

源码、浏览器、安装包和真实模型的证据分别记录。自动化用本地假模型和隔离目录，不把协议回归计为真实服务验证。发行清单的源码提交和产物校验值为本版准确来源；发布前应补齐对应包的验收记录。

- App 当前只提供 macOS 14+ Apple Silicon。Intel Mac、Windows App 与 CLI Windows 未验收。
- 没有 Developer ID/公证，也没有原生 ZIP 自动安装；App 更新通过校验后的 DMG 手动替换。
- CLI 安装仍需网络下载匹配平台的运行组件；CLI 不包含桌面文档编辑器、Swift helper 或本机 CAD 环境。
- Blender 需要单独安装。电脑操作需要屏幕录制、辅助功能及当前会话的人工窗口授权。
- 麦克风真实录音、首次权限授权、普通下载的 Gatekeeper 批准、干净机器安装和用户自选真实模型任务需要对应环境的人工验收。尚未完成的项目不能计为通过。
- 仓库保持私有时，未获访问权的用户不能直接下载 Release；公开入口需在发布时开放。私有 App 更新认证接入尚未完成。

升级前结束任务并备份重要数据。安装新版本后检查历史、模型连接、文档和草稿恢复，不通过删除用户数据排错。后续测试版使用递增 beta 版本，反馈请附版本、系统和芯片、安装方式、复现步骤及脱敏错误，通过同仓库 issue 跟踪。
