# 旧基础形体工程

仅在 cad_read_model 返回 version:1 时读取。

每轮用户请求的首次修改前，都先调用 cad_read_model 获取当前模型和稳定特征 ID。上一轮的读取不能替代本轮读取，用户可能已经手工改过模型。用户要求“更复杂、更真实、优化一下”等继续改进时，继续编辑当前绑定的同一资源，保留用户新增的特征和调整，只有明确要求另存版本或新建文件时才创建另一份。多个特征的新增、替换和删除优先用 cad_edit_parts 的 upsert/remove 数组一次提交；单个改动也可用 cad_upsert_part / cad_remove_part。不需要逐个试调用。

模型版本为 1，单位 mm；所有形体以中心为原点。size 是长方体的 X/Y/Z 尺寸；圆柱沿 Z 轴，用 radius/height；球体用 radius。position 是中心位置，rotation 是绕 X/Y/Z 的角度（度）。更新特征时传完整参数，遗漏字段会恢复默认值。

rotation 只绕形体自身中心改变朝向，不会改变 position，也不会绕模型原点公转。做机身周围的四片尾翼时，四个中心必须分别放在 [0,r,z]、[r,0,z]、[0,-r,z]、[-r,0,z]，再分别设置 0°/90°/180°/270° 的朝向；不要四片都用同一个 position。更一般的径向排列用中心 [r*cos(θ),r*sin(θ),z]，朝向另设。保存后除了读回尺寸，也核对不同特征的中心与方向，避免声称重叠的形体已经均布。

特征按列表顺序求值：add 合并实体，cut 从此前累计实体中切除。首个特征必须是 add。通孔的切除体应略长于工件厚度；明确尺寸、位置和方向，不靠视图截图估计数值。需要修改多个已有特征时先确认依赖关系，不删除实体后留下首个切除体。

cad_edit_parts 保留未涉及的特征；已有 ID 保持原顺序，新 ID 按数组顺序追加。只校验最终模型，整批成功或整批失败，一次撤销可恢复整批。同一 ID 在一批中只能出现一次。需要改动实体及其切除体时放在同一批，避免留下无效中间状态。

读取工具让你获得当前设计；编辑工具在提交时校验已读版本、自动管理版本并保存，不需要传 revision；同一会话对同一模型的调用由运行时排队。本轮完成首次读取后的连续修改，只在工具实际报告冲突时重新读取并结合用户修改重算；工具返回 nextAction 时先按其指示恢复。不预先讨论版本或询问用户如何调用工具，也不用 write/bash 覆盖资源文件。保存后读回模型确认参数；回复所做的设计改动、尺寸和简化假设，不把网格近似或截图当作制造精度验证。

旧形体格式支持长方体、圆柱、球体、合并和切除，最多 64 个特征。JSON 保留参数，STL 为三角网格且文件本身不声明单位，按毫米使用。STL 从 CAD 界面导出；不要声称已有 STEP/DWG、约束求解、圆角、装配或 FreeCAD 接入。
