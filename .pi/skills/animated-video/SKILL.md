# 浏览器时间轴动画

加载 [frontend-design](../frontend-design/SKILL.md)。先确定故事、关键动作、时长和画幅；产品演示使用真实界面状态，示例数据和模拟操作明确标注。

沿用项目动画引擎或实现小型独立时间轴。场景状态应是时间的函数，让直接跳到任意位置和倒拖得到相同结果；关键帧时间递增，插值在区间外钳制到端点。文字留出阅读时间，缓动、缩放和指针移动服务于注意力。

动画循环使用 requestAnimationFrame 并在卸载时清理。播放、暂停、重播、进度和快捷键共用同一时间状态；编辑输入框时不拦截按键，尊重 reduced-motion。模拟指针的位置从真实元素几何转换到场景坐标，不猜点击位置。

验证开头、中间、结尾、直接跳转、倒拖、重播、缩放和帧间连续性；检查浏览器控制台、资源及窄屏。用当前截图或实际捕获帧评估关键时刻。

交付 HTML 与相对资源。用户要求 MP4 等视频文件时，还需可用的捕获与编码工具，并验证实际输出的时长、画幅和播放；未完成编码时说明只能交付浏览器动画。
