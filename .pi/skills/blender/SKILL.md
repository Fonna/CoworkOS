# Blender collaboration

Use this workflow for a bound Blender resource or an explicitly delegated resource. For a new project, enable_tools({groups:["applications"]}) first. In a delegated candidate scope, edits create private candidates; report the latest candidatePath to Main rather than claiming the shared scene was saved. The core loop is read → query details → modify → render and inspect. Start each user request with `blender_read_scene`; the saved scene, parameters, object IDs and selection are authoritative. Object results default to 100 per page; follow nextOffset while revision stays the same, or filter by ids/name/type. Counts and bounds cover the whole scene. Set includeSource=false when code is not needed. Creation uses `project/atria-blender+json`; an empty project has no geometry until a successful run.

Use `blender_apply_operations` for object transforms, names and basic Principled material edits. Positions use Blender scene units, rotations use degrees and transforms are local to the parent. Stable IDs identify objects independently of names; do not overwrite their `atria_id` property. Preserve manual changes and objects unrelated to the request.

Use `blender_run_python` for modeling. It loads the existing native scene into a candidate process, executes the source, then calls `main(p)` if defined. `parameters` supports nested JSON and merges explicit top-level overrides into saved parameters (no implicit deep merge). For temporary patch scripts, set saveSource=false to preserve the modeling draft. Target existing objects by name or `atria_id`; avoid creating duplicates on subsequent runs. Use `resetScene` only when the request calls for rebuilding the entire scene. Prefer `bpy.data` and BMesh APIs where possible; `bpy.ops` depends on the current mode and selection. Use `blender_get_api_reference` to inspect the installed version rather than inventing APIs.

Use `blender_query` to inspect native collections, material/geometry nodes, modifiers, bones or animation without committing. Return bounded JSON from main(p) or a global result; never return bpy objects. The query loads a saved-scene copy and discards all changes; it does not execute the modeling draft. API queries, native queries and previews do not replace the required scene read before mutation.

The candidate must contain renderable mesh geometry and stay within 1000 objects / 2 million evaluated triangles. No user or workspace files, credentials, networking or arbitrary subprocesses are available to model Python. Dependencies must already be embedded in the native scene. Python errors, timeout, cancellation and revision conflicts do not commit the candidate. Re-read after a conflict and combine the new request with the latest manual edits.

Successful runs return actual object and mesh statistics, bounded `print` diagnostics and a native PNG preview. Check both measured geometry and visual feedback when the model connection supports images. Numerical validity does not prove visual quality. For text-only connections, report the diagnostic evidence and do not claim to have inspected an image.

The workbench displays a GLB derivative; `.blend` retains full modifiers, nodes and scene data. `blender_preview` reads the current saved preview. `blender_render` returns a higher-quality CPU Cycles image without changing the scene. Specify camera by stable ID or name, frame, width/height, samples and denoise to inspect multiple views and animation poses. Each returned image identifies its source snapshot. Rectangular width/height must be paired and cannot be combined with square resolution. Preserve the saved lighting and composition; automatic lighting is only used when no scene camera exists. Use `export_resource` with `blend`, `glb`, `png` or `python` for real task deliverables. A workbench JSON manifest alone is not a portable Blender project.

PNG export is an independent CPU Cycles render; preview/render options are not carried over. Defaults are 768×768 and 32 samples, even when the saved scene has another resolution. Pass options for each deliverable: square resolution OR paired width and height (64–2048), samples (1–128), camera, integer frame, denoise, timeoutSeconds (1–600). Run/edit/import default to 180 seconds, render/PNG export to 300 seconds, and query to 60 seconds. Increase timeoutSeconds up to 600 for expensive work without reducing requested geometry or render quality. Overrides do not change the scene. Verify the actual published dimensions returned by export_resource.
