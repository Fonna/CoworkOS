# 高保真设计探索

加载 [frontend-design](../frontend-design/SKILL.md)，读取品牌、真实内容和使用场景。先确定需要比较的设计决策，再制作有明确差异的方案，例如信息密度、导航、排版或视觉锚点。

所有方案使用相同内容、数据与视口，让差异可比较。页面高度由内容决定；固定画幅只用于用户明确要求的设备尺寸或裁切预览。静态方案可用普通 HTML、CSS 和页内切换，不依赖宿主画布协议。

标注方案的适用场景和取舍，不用纯换色假装不同信息架构。已有产品沿用设计系统，用户未要求时不整体重做。检查长标题、空态、窄屏与内容溢出，用当前截图验收后给出推荐方案和依据。
