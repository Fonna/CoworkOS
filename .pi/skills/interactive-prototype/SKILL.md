# 可交互原型

先加载 [frontend-design](../frontend-design/SKILL.md)。直接呈现应用界面，使用项目的组件、路由和状态管理；多方案用页内切换或既有路由，不把交互页面包在静态画布里。

- 从同一状态派生列表、详情、计数和筛选结果。示例数据须明确标注，不能宣称本地状态已经实现后端或多人同步。
- 每个可见控件都连接到实际动作：筛选更新结果、保存更新数据、取消不提交、删除更新关联视图。未实现的动作移除或禁用并说明原因。
- 表单覆盖必填、格式错误、提交成功与失败；异步操作有 loading、防重复提交和恢复路径。
- 多步流程明确前进、返回、刷新时是否保留输入。只在需要跨页或刷新保存演示状态时用 localStorage，处理无效数据与存储不可用。
- 模态框可关闭，焦点进入并在关闭后回到触发控件。语义控件和键盘操作可用，动效尊重 reduced-motion。

走完整主要用户流程，检查错误输入、取消、重复操作、导航、刷新和空态，并查看控制台及窄屏截图。验证结果区分 mock 数据和实际 API；交付按 frontend-design 的工作目录与发布流程执行。
