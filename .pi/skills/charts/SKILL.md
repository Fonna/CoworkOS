# 图表与视觉编码

先读 [图表方法与实现](references/chart-design.md)。每张图回答一个主要问题，标明单位、时间范围、来源和必要的不确定性；示例数值明确标注。

数据决定图型：时间趋势用折线，分类比较用条形，分布用散点、直方或箱线，部分与整体用少量扇区或树图，关系用网络或流向图。不要用面积和颜色制造数据中不存在的差异。

沿用项目的图表库；ECharts 可用时复用已安装版本，静态小图可用 SVG/CSS。不要引用平台专用 CDN 或为演示强行更换依赖。图表随容器变化 resize，离开页面时销毁实例及监听器。

用源数据复核系列、排序、比例、单位、缺失值和极端值。检查标签、图例、颜色语义、窄容器和空数据；可交互图表实测筛选与 tooltip，静态图提供可读标签及文本结论。
