# 图表方法与实现

| 信息关系   | 可选图型         | 核查                         |
| ---------- | ---------------- | ---------------------------- |
| 时间趋势   | 折线、面积       | 时间顺序、缺失时段、坐标范围 |
| 分类比较   | 横向或纵向条形   | 排序、单位、零基线           |
| 分布       | 直方、箱线、散点 | 分箱、样本量、离群值         |
| 部分与整体 | 饼图、树图、条形 | 总和与分母、类别数量         |
| 关系与流向 | 网络、桑基、树   | 节点映射、链接约束和来源     |
| 日程       | 时间轴、甘特     | 开始结束时间、时区和重叠     |

颜色编码分类时使用一致色相映射；编码顺序或强度时使用连续色阶；编码相对中点的偏离时使用有明确中点的分歧色板。没有编码含义时减少颜色变化。仪表盘保持同一分类、坐标口径和数字格式。

## 浏览器实现

优先复用已有库与锁定依赖。需要 ECharts 时先检查项目安装版本及对应 API；静态小图可使用 SVG，离线产物包含运行所需资源。第三方库和字体保留许可。

ECharts 在有实际尺寸的容器中初始化，监听容器尺寸变化并调用 resize。React 等框架在卸载时 dispose 并清理 observer/监听器；数据变化更新 option，避免累积旧系列。不要修改图表库源码。

## 验收

按源数据复核系列、数值、分母、单位、时间和过滤。检查无数据、只有一个点、负值、缺失值、长标签及小容器。tooltip 和颜色不能是唯一的数据表达方式，提供可读文本或表格。

实测筛选、图例及 resize；截图检查标签、裁切、对比与视觉编码。科学或出版图按用户要求使用标准绘图工具生成独立文件，不能用网页截图冒充指定格式。
