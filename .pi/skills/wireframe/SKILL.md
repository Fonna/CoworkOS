# 线框图与故事板

先确定用户需要完成的任务，以及进入、操作、结果和恢复状态。用灰阶、基础字号与清晰的标签展示内容分组、主次和导航，不先投入装饰。

使用真实字段名和具有代表性的内容长度。只为真实的流程步骤编号；标注每个关键操作的结果、必需输入、返回路径及错误状态。多屏故事板保持同一视口和内容口径。

用普通 HTML/CSS 或项目已有设计工具交付；需要可点击流程时加载 [interactive-prototype](../interactive-prototype/SKILL.md)。先验证用户能找到主要动作，再进入 [hi-fi-design](../hi-fi-design/SKILL.md)。交付说明覆盖了哪些状态与尚待确认的产品决策。
