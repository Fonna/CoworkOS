# 数据报告与看板

先检查输入数据的字段、类型、时间范围、单位、缺失项和去重规则。确定读者需要回答的问题，再规划指标、对比和图表；视觉部分加载 [frontend-design](../frontend-design/SKILL.md) 与 [charts](../charts/SKILL.md)。

- 为每个指标记录数据来源、公式、过滤条件、分母和时间口径。增长率和百分点不同，缺失值不能默认为零。
- 将解析、清洗与指标计算集中在可复核的数据处理代码；卡片、图表、表格和文字结论从同一结果派生。
- 保留原始数据及处理步骤；选取几个结果人工或用独立计算复核。日期、地区和其他筛选同时更新所有相关视图。
- 分开描述观测、解释和建议。不能将相关性写成因果，不能从示例数据给出真实业务结论。
- 全部页面使用一致的数值格式、色板、分类和坐标口径。主要图表承载决策，其余内容提供证据，避免堆无关 KPI。

交付入口、所需数据和计算源码，注明覆盖范围及数据限制。验收无数据、缺失字段、重复记录、极端数值、筛选、刷新和窄屏；用 `read_image` 检查实际渲染。
