# 叙事与浏览器交付

## 页面计划

为每页记录标题结论、证据和主要视觉。标题连起来应能说明故事；主题、机制、比较、证据和行动按读者需求组织。图表有单位与来源，图片保持比例，数字来自资料。

保持字体、边距和色板一致，用不同的信息形式形成节奏：图表、图解、对比、截图或少量文字。内容过密就精简、拆页或移至备注。图表和图片是信息载体，不能用装饰填满空白。

## 导航与打印

使用语义 section 表示页面和实际按钮表示前后导航。键盘监听忽略 input、textarea、select 和 contenteditable，处理首尾边界。非当前页不可抢焦点；交互控件和链接仍按自己的行为工作。

为窄屏提供可读布局或明确缩放方式。打印样式展示全部页面，隐藏导航，每页独立分页并检查实际页数。基础样式保留可见终态；动画由当前页状态与 prefers-reduced-motion 门控，打印静态内容可读。

## 保存与交付

如实现浏览器编辑，使用明确的下载或项目存储接口，刷新后核实内容保留。没有保存实现时不要显示会丢失内容的编辑控件。

通过本地 HTTP 验证资源、导航、键盘、输入和打印，逐页查看当前截图。交付 HTML、图片及运行依赖；PPTX 使用 presentations 的可编辑生成及验证流程，已绑定文稿使用 PPTist 修订工具。
