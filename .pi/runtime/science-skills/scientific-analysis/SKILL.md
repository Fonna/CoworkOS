# 可复现科学数据分析

先确认源文件、列含义、单位、缺失值及用户要回答的问题。检查有限样本和取值范围，保留原文件，避免将示例数据当成真实观测。

1. 搜索审核目录时使用任务描述，例如“标准曲线拟合”“去背景后找峰”或“dimensionality reduction”。Main 先按需启用 science；委派智能体直接使用已有科学入口。对匹配函数先 `science_describe`，核对参数、单位、依赖、适用条件和数组界限，再 `science_run`。不要把代码、文件路径或执行选项传给 `science_run`。
2. 已有函数适用时优先使用；需要组合 NumPy、SciPy、CSV 读取或绘图时，通过现有文件工具保存脚本，再由命令工具使用本 Run 明示的基础 Python 执行。`python` 不一定是所选解释器。命令工具若接受 command/args，分别提供解释器与参数，避免假定存在 shell 展开。后台长任务仅在已有 jobs 能力可用时使用对应工具。
3. 保留数据变换顺序、参数及模型选择。基线校正、寻峰、标定和 PCA 分别回答不同问题，不能用一次峰检测代替全部步骤。只执行任务需要的步骤，不机械串联函数。
4. 对关键结果做独立数值检查，检查输入边界、残差或重建结果。不要从拟合或相关关系直接推导因果。依赖缺失时保留已有分析与错误信息，说明对应环境需要哪些包；普通文件工作和无需该依赖的计算仍可继续。
5. 用已有文件工具写出足够复现的脚本、结果表或图及简短方法说明，记录输入路径、所选解释器、实际依赖版本、单位与假设。Main 使用现有产出物发布工具交付最终文件；委派智能体将候选结果放在自己的 deliverables 目录供 Main 审阅。

函数目录与环境选择固定于当前 Run。不要为了使用新函数而自行改变旧 Run 的版本或升级共享 Python 环境。
