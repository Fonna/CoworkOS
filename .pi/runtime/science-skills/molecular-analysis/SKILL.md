# 分子结构与质谱分析

先区分输入是分子结构、离散质谱峰表还是实验原始谱图，以及用户需要结构描述符、分子式、质量或同位素匹配。不要把峰表分析当成结构鉴定。

1. 使用 `science_search` 发现当前 Run 的审核函数，再用 `science_describe` 查看严格参数、单位、输入限制和来源。需要时先校验 SMILES，再计算所需属性；规范 SMILES 只作为该 RDKit 版本的序列化，不作为通用化学身份。
2. 平均分子量 MolWt 与单同位素精确质量不同。读取各函数定义，保留同位素、立体和电荷假设；不要把中性结构的质量直接声称为带电离子、加合物或实验 m/z。
3. 质谱峰解析、理论同位素模式和观测簇匹配是独立步骤。核对原始强度、阈值、电荷与容差，保留用户提供的数据；只计算任务需要的项目。峰匹配不能单独证明某种分子结构。
4. 多分子或其他 RDKit 分析可用现有文件/命令工具写脚本，明确调用本 Run 选择的 chemistry/RDKit Python。基础 Python 与化学 Python 可能不同。依赖版本与环境由宿主管理，记录实际使用版本；不要为了分析偶然升级共享环境。目录内函数优先使用审核入口，`science_run` 不执行自定义脚本。
5. 保存输入结构、参数、结果、单位、失败记录与可复现脚本。无效结构不能替换为猜测结构继续计算；一项失败也不能伪装成零值。通过现有 Task 文件及产出物流程交付，不修改原数据。
