# 回归测试

执行入口见 [本地测试指南](../docs/testing-local-run.md)。Node 用例在本目录，浏览器用例在 `../e2e/`，发布用例规划/执行在 `release/`；新增测试应可被入口自动发现。

- 断言用户可观察行为、错误、数据和恢复，避免复制实现或仅匹配源代码。新增 runner/gate 要验证成功与拒绝路径。
- 每个 fixture 使用 `mkdtemp` 和自己的端口、工作区/配置；在清理钩子中关闭 server、子进程、watcher，等待结束后删除目录。
- 确定性验证使用本地假模型与真实 Pi 进程，不调用用户模型账户。真实模型、Electron、系统权限和包装安装分别执行、记录。
- 测试不能扫描/删除真实工作区、Supervisor 锁或用户文档。用 fixture 设置环境变量并过滤继承的模型/目录配置。
- 新模块至少覆盖其可观察行为与主要失败/恢复路径。已有缺陷修复先添加能复现的回归。
- 报告通过、失败、跳过和依赖条件；CI、原生或干净安装未执行就写未验证。
