# 共用前端

`app.js` 装配页面状态和控制器；新行为优先进入 `assets/controllers/` 或 `assets/workbench/` 的现有模块。Web 与 Electron 共用页面，浏览器模块不导入 Node。

- 控制器用明确端口/回调协作，不跨模块直接修改私有状态或复制请求逻辑。
- 异步操作捕获 Task、Tab、资源、草稿和导航身份，晚返回不覆盖新的选择、草稿或会话。刷新复用焦点与滚动位置。
- 编辑器按 revision 保存；冲突保留本地文本。关闭、重启、切换资源和退出应用都必须处理未保存修改。
- SSE 连接、重连、去重和清理由 connection controller 管理；不要另开一套事件通道。
- 产品 UI 只展示用户需要的信息，工程诊断放到日志/文档。颜色、图标、菜单、焦点和布局沿用 [UI 约定](../docs/development.md#应用-ui-约定)。
- 全程遵守[仓库界面设计要求](../AGENTS.md#界面设计)，包括先删冗余文案、按需 tooltip、首次使用的操作清晰度，以及可访问性和危险操作后果提示。
- avoid unnecessary secondary labels and descriptions. Let the layout do the explaining.
- 重写界面先移除冗余标签、状态副行、教学段落和操作回执，再用层级、间距与清晰的主操作保证首次使用可理解；补充信息优先按需显示，不给每个区块添加常驻说明。
- 保留必要的表单标签、可访问名称与状态。精简文案不能移除危险或不可逆操作的后果提示；列表悬浮默认只用轻背景，不抬升、不添加装饰阴影。

验证可见行为使用对应 `e2e/*.spec.js`，补充 Node 的控制器/会话测试。详情见 [代码地图](../docs/code-map.md)，不要把只匹配 HTML 文本的断言当成操作验收。
